# ReLoop NTU

Interactive prototype for **"Why a campus-wide reusable container system may not work at NTU… yet"**
CC0006 Project Showcase · Cluster B, Table 12

ReLoop turns the group's recommendation (pilot first, measure honestly, scale only if the full loop works) into a working product demo with five views:

| Key | View | What it shows | Slides it supports |
|-----|------|---------------|--------------------|
| 1 | **The loop** | Animated six-stage loop (Borrow, Eat, Return, Collect, Wash, Redistribute). Click a stage to see what happens, where it breaks and what the pilot measures. NTU context and the BYOC campaign results. | Janelle, Rishaan |
| 2 | **Student app** | Phone prototype inside the NTU pass app: borrow at a pilot stall, 48-hour reminder, 2-day grace period, S$20 fee, return to the right halal / non-halal chute. | An Qi (Safeguards, Concerns) |
| 3 | **Operations** | One simulated day of return bins filling across a schematic campus. Compare "collect when full" with fixed rounds, and the 3-point pilot with a 12-point campus-wide rollout. Lunch top-up planner that keeps pools separate. Wash hub batches by pool. | Rishaan, Kyra |
| 4 | **Break-even lab** | How return rate decides whether a container ever beats a disposable (LCA break-even 4 to 200+ uses). Return-point trade-off. Cost of separate pools. | Prisha |
| 5 | **Pilot scorecard** | Tier 0 → Pilot → Review checklist, then Go / Pivot / No-Go from three criteria with editable targets. | Sachin |

---

## Fastest way to present (no installation)

Open **`dist-single/index.html`** by double-clicking it. It is one self-contained file (fonts included), works offline, and runs in Chrome, Edge, Safari or Firefox. Copy it onto a USB stick as a backup.

## Run the source code

Requires [Node.js](https://nodejs.org) 18 or newer.

```bash
cd reloop-ntu
npm install        # once
npm run dev        # opens http://localhost:5173 with live reload
```

Other commands:

```bash
npm run build          # production build into dist/ (host on any static server)
npm run build:single   # rebuild the single offline file dist-single/index.html
npm run preview        # serve the dist/ build locally
```

## Presenter controls

- **Keys 1–5** jump between views. **[ and ]** step back and forward. Links also work: `index.html#student`, `#ops`, `#lab`, `#pilot`.
- **Student app → Demo clock** (right side): *Jump to reminder* shows the 48 h push notification, *Jump past grace* charges the S$20 fee, *Reset demo* starts over.
- **Operations**: press play to run 08:00–20:00, or drag the time slider. Switch scenario and collection rule at the top of the console.
- **Pilot scorecard**: switch between *Week 4 result* (Pivot), *If it goes well* (Go) and *If returns slip* (No-go). Edit any target to see the decision move. *Restore agreed targets* undoes edits.

### Suggested 3-minute demo

1. **The loop**: point at the dots leaving the ring at Return and Wash. "Even at 95% returns, only 29% of containers reach use 20."
2. **Student app**: Jump to reminder → Jump past grace → Return → pick the *Non-halal* chute to show it stays closed → use the halal chute.
3. **Operations**: Play the pilot day, then switch to *Fixed rounds* (half-empty pickups) and *Campus-wide* (containers turned away at full bins).
4. **Break-even lab**: drag *Return rate* from 95% to 97% and watch the verdict flip.
5. **Pilot scorecard**: show Pivot for week 4, then *If returns slip* for No-go. Close on the final recommendation.

## What is real and what is simulated

Everything runs in the browser. There is no backend.

| Simulated | How |
|-----------|-----|
| NTU pass app login, push notifications, payments | Generated by the demo clock |
| Container tags and chute readers | Random tag IDs; chute checks the container's pool |
| Return bin fill levels and collections | Model of a day with lunch and dinner peaks (`src/lib/model.ts`) |
| Pilot results (4 weeks) | Three hand-written data sets (`src/views/Scorecard.tsx`) |
| Material presets, wash water/energy, return-point curve | Illustrative constants inside the ranges in the slides (`src/lib/model.ts`) |

Facts taken from the slides: 16 canteens, up to 30,000 diners a day, Semakau landfill, the EarthLink NTU BYOC campaign (10–30¢ discounts, 222 uses, 43 participants), the 48 h / +2 day / S$20 safeguards, LCA break-even of 4 to 200+ uses, Tier 0 → Pilot → Review, and the Go / Pivot / No-Go criteria. The campus map is schematic and not to scale.

## Editing

| To change | Edit |
|-----------|------|
| Colours, fonts, spacing | `src/styles.css` (tokens at the top) |
| Loop stage text | `STAGES` in `src/views/Overview.tsx` |
| Stalls, return points, map positions | `src/data/campus.ts` |
| Model assumptions | `src/lib/model.ts` |
| Pilot targets and weekly data | `CRITERIA` in `src/views/Scorecard.tsx` |

After editing, run `npm run build:single` to refresh the offline file.

## Project structure

```
reloop-ntu/
├─ dist-single/index.html   ← prebuilt offline file for presenting
├─ index.html               ← Vite entry
├─ src/
│  ├─ App.tsx               ← shell, navigation, keyboard shortcuts
│  ├─ styles.css            ← design tokens and all styles
│  ├─ components/           ← Loop, LineChart, small UI controls
│  ├─ data/campus.ts        ← stalls, return points, map layout
│  ├─ lib/model.ts          ← break-even, collection and wash models
│  └─ views/                ← Overview, StudentApp, Operations, Lab, Scorecard
├─ package.json
└─ vite.config.ts
```

Stack: React 18, TypeScript, Vite, lucide icons, self-hosted Anton and Albert Sans fonts. No UI framework, no chart library: the charts are hand-built SVG so they match the slide styling.
